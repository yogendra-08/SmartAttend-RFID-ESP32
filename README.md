# SmartAttend-RFID-ESP32
Smart Attendance System using ESP32, RC522 RFID Reader, LCD Display, LEDs and Buzzer for automated attendance tracking and real-time attendance management. Inspired by common ESP32 + RFID attendance architectures used in IoT projects.

# SmartAttend-RFID-ESP32

Smart Attendance System using ESP32 and RC522 RFID Reader.

## Features
- RFID Based Attendance
- LCD Display
- LED Indicators
- Buzzer Alerts
- Student UID Mapping

## Components
- ESP32 DevKit V1
- RC522 RFID Reader
- RFID Cards
- 16x2 LCD I2C Display
- Green LED
- Red LED
- Buzzer
